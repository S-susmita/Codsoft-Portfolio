# 🌐 Personal Portfolio Website

A responsive personal portfolio website developed using **HTML, CSS, and JavaScript** to present my profile, technical skills, projects, and professional interests.

## 📌 Overview

This portfolio was developed as a front-end web development project to create a clean, structured, and responsive personal website.

The website introduces my background as an **Artificial Intelligence student** with an interest in **Artificial Intelligence, Machine Learning, programming, and web development**. It provides a simple way to explore my skills and projects through an organized interface.

## ✨ Key Sections

### 🏠 Home

Provides a brief introduction along with a call-to-action button to explore the projects section.

### 👩‍💻 About Me

Highlights my interests in Artificial Intelligence, Machine Learning, programming, and web development.

### 🛠️ Skills

Displays my current technical skills:

* 🐍 Python
* 🤖 Artificial Intelligence
* 🧠 Machine Learning
* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 🔗 GitHub

### 📂 Projects

The portfolio showcases three projects:

* **Portfolio Website** – A personal website created using HTML, CSS, and JavaScript.
* **Calculator** – An interactive calculator for performing basic arithmetic operations.
* **Landing Page** – A responsive landing page designed with a clean and user-friendly interface.

### 📞 Contact

Provides contact information along with GitHub and LinkedIn details.
